# Todo Vanilla JS

Vanilla JavaScript를 활용하여 구현한 Todo 웹 애플리케이션입니다.

사용자는 날짜별로 할 일을 관리할 수 있으며, 주간 캘린더를 통해 원하는 날짜를 선택하고 해당 날짜의 Todo를 확인할 수 있습니다. 또한 상태별 필터링과 로컬스토리지 저장 기능을 제공하여 브라우저를 새로고침해도 데이터를 유지할 수 있습니다.

## 주요 기능

### Todo 관리

- Todo 추가
- Todo 수정
- Todo 삭제
- Todo 완료 처리
- 완료된 Todo 취소선 표시

### 주간 캘린더

- 월요일 ~ 일요일 주간 뷰 제공
- 이전 주 / 다음 주 이동
- 날짜 선택 기능
- 날짜별 Todo 개수 표시
- 오늘 날짜 강조 표시

### 필터 기능

- 전체 보기
- 진행 중 보기
- 완료 보기

### 데이터 저장

- LocalStorage를 활용한 데이터 저장
- 새로고침 후 데이터 복원
- JSON.stringify / JSON.parse 사용

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript

## 실행 방법

1. 프로젝트를 클론합니다.

```bash
git clone <repository-url>
```

2. 프로젝트 폴더로 이동합니다.

```bash
cd todo-vanilla
```

3. index.html 파일을 브라우저에서 실행합니다.

또는 Live Server를 사용하여 실행할 수 있습니다.
